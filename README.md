# ☕ Café Loukkos: Data-Driven Agroforestry for Moroccan Coffee

## 📌 Project Overview
This repository contains the pitch deck and financial modeling work for **Café Loukkos**, a project developed for the **Nestlé Eco-Innovate Hackathon 3.0 (Case B: The Moroccan Cup)**. 

Our challenge was to determine if Morocco could grow its own green coffee to replace imports. Our solution proposes a 12-month gated pilot to grow Arabica coffee under existing avocado canopies in the Larache-Loukkos region.

**Result:** 🏆 **2nd Runner-Up** out of 10 elite teams.

## 📊 My Role & Technical Contribution
As the data and operations lead, I was responsible for:
*   **Financial Modeling:** Building the Excel model to calculate the cost per kg of local coffee (40.3 MAD/kg) versus the import benchmark (43.78 MAD/kg). 
*   **Pilot Design:** Designing the 1.5-hectare pilot layout (intercropping avocado, coffee, and fava beans).
*   **Data Analysis:** Calculating the water usage (5,400 L/kg) and the projected farmer income (+65,000 MAD/ha/yr).
